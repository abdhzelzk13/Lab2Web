Praktikum 2 HTML Lanjutan bertujuan untuk memahami penggunaan tabel,

Materi yang dipelajari pada Praktikum 2 meliputi:

4. Radio Button dan Checkbox
5. Select dan Textarea

7. Semantic HTML
